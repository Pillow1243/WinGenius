## ۱. مشکل نسخه‌ی ۵

۲۵۴ ابزار داشتیم و هر کدام **یک کار روی یک فایل**. برای «۴۰۰ عکس را کم‌حجم کن و ZIP کن»
کاربر باید ۴۰۰ بار دکمه می‌زد یا خودش اسکریپت می‌نوشت. گردش‌کارهای نسخه‌ی ۳ هم فقط
«ابزار ۱ ← ابزار ۲ ← ابزار ۳» را می‌دانستند: بدون تکرار، بدون شرط، بدون تحمل خطا.

## ۲. چیزی که نسخه‌ی ۶ اضافه کرد

هر گام یک جریان حالا چهار کنترل دارد:

| کنترل | پیش از ۶.۰ | در ۶.۰ |
|---|---|---|
| تکرار روی فایل‌ها | نبود | `foreach` با glob، `**` بازگشتی، `*.{jpg,png}` و `{item*}` |
| شرط | نبود | `when`: `{prev} endswith .pdf`، `{prev_all} not empty`، `2 < 10` |
| تلاش مجدد | نبود | `retries` |
| خطا | کل جریان می‌مرد | `on_error: continue` ⇒ وضعیت `partial` |

و سه چیز که «جریان» را از یک فایل JSON بیرون آورد:

1. **دسته‌ی یازدهم در خود برنامه** — اجرا، ساخت خودکار از پوشه، بازرسی، توضیح، خروجی
   اسکریپت، کتابخانه‌ی ۱۰ جریان آماده.
2. **خط فرمان** — `--flows`، `--run-flow`، `--lint-flow`، `--explain-flow` با `--json`.
3. **`flowkit`** — لایه‌ی بدون Qt: بازرسی دوزبانه، توضیح شماره‌دار، ساخت خودکار،
   تبدیل جریان به اسکریپت پایتونِ مستقل.

## ۳. امتحان کنید

```bash
# ۱) ببینید چه جریان‌هایی آماده است
python main.py --flows

# ۲) جریان را روی پوشه‌ی عکس‌ها اجرا کنید (فشرده‌سازی + PDF + ZIP)
python main.py --run-flow photo_pdf_pack --file ~/Pictures --out ~/out --json

# ۳) از هر پوشه‌ای جریان بسازید
python main.py --run flow_build --set folder=~/Downloads

# ۴) قبل از اجرا بازرسی کنید (بدون تغییر چیزی)
python main.py --lint-flow my_flow.json

# ۵) جریان را به اسکریپت پایتون تبدیل کنید
python main.py --run flow_export --set flow=photo_pdf_pack --set out_dir=~/out
```

در برنامه: **منوی رادیالی ← جریان هوشمند**، یا شیت گردش‌کارها (`Ctrl+3`).

## ۶. چه چیزی عمداً انجام نشد

- **اجرای موازی `foreach`** — فعلاً یکی‌یکی (ترتیب قابل پیش‌بینی، مصرف حافظه‌ی کم). در نقشه است.
- **ویرایشگر گرافیکی جریان** — جریان‌ها JSON می‌مانند؛ UI فقط اجرا/بازرسی/توضیح می‌کند.
- **عبارت‌های پیچیده در `when`** — بدون پرانتز و ریاضی؛ برای منطق سنگین از ماکرو استفاده کنید.

## ۷. رفع باگ‌هایی که خودِ تست‌ها پیدا کردند

| باگ | حالا |
|---|---|
| `flow_run` بدون `check_only` ورودی می‌خواست | فقط وقتی واقعاً لازم است |
| `image_deskew` همیشه ۰° می‌داد (`minAreaRect`) | زاویه از خطوط Hough، میانه‌ی زوایا |
| `archive_encrypt` پیام «N٪ کوچک‌تر» با عدد منفی | «N٪ بزرگ‌تر» |
| `opencv` ۵.۰ بدون کاسکادهای چهره | سقف `<5` پین شد و `image_face_blur` تست دارد |
